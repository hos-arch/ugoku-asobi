# うごく あそび 仕様（ugoku-asobi）
参考：療育の実践書（「身体の調節」の課題を参考にした）。この仕様は、同書の考え方をもとに、私たちが画面用に解釈した試作です。

## 0. 考え方
- 子どもが画面を傾けて遊ぶゲームではなく、体の動きを経験するための教材。画面は、体の動きを「見通す・確かめる・リズムをそろえる」ための補助。
- 成功の基準は、画面のゴールではなく、画面の外での体の動き。
- 本物 → 画面 → 本物の順で使う。
- **端末は大人が持って傾ける。子どもは端末を持たない。** 子どもに任せると、指示が入らない・画面の表示で遊んでしまうことがあったため。

## 1. ねらい（同書から）
- 体が揺れる感覚を楽しみ、緊張感やリラックス感を体験する。
- 姿勢を変えることに慣れる（手押し車など）。
- 遊具に合わせて体を動かせるようにする。
- 留意点：はじめは抱いたり、体を支えたり、手をとったりして徐々に慣れさせ、楽しさがわかるようにする。安全には十分注意する。

## 2. 場面（子どもの画面は文字なし）
### すすむ（手押し車）
- 横から見た絵。子どもが手押し車をしていて、うしろの大人（顔は描かない）が足を持つ。左から右へ。
- 大人が端末を前に傾けると、手を交互に出して進む。水平に戻すと、ゆっくり止まる。うしろへは進まない。
- 動き出し：反応の角度を超えて約0.3秒。止まる：反応の角度の約60%を下回って約0.4秒。速さは傾きに比例し、約20°で上限。
- 旗（またはおうち）に着いたら止まり、星とやわらかい音。次の道は、端末が水平近く（約6°以内）に戻って約0.5秒たってから。
- 道の長さ（みじかい・ふつう・ながい）、進む速さの上限（ゆっくり・ふつう）。

### ゆれる
- ゆりかご（赤ちゃんが寝ている）・ブランコ・ボート。
- 大人が端末を左右に傾けると、同じ向きに傾く。止めると、ゆらゆら → ふわっと止まる。約20°で、いちばん大きく揺れる。
- 自動でゆれる（約3.4秒で1往復）も選べる。端末を置いて、大人が両手を使うときに。
- ゆれの幅（小・中）、ゆれの音（なし・小・中。揺れに合わせて左右にゆらぐ、やわらかい音。歌詞のある曲は使わない）。

### のる
- 遊具の絵（2：トランポリン・ブランコ／3：＋すべり台／5：＋三輪車・ローラースケート）。
- 押すと大きくなり、その遊具で遊ぶ様子がゆっくり見える。もう一度押すと戻る。乗る前の予告に使う。
- ブランコは、端末を前後に傾けると揺れる（傾きが使えないときは、ゆっくり自動で）。ローラースケートは、大人が手をつないでいる。
- 遊具の動きは、速すぎない・高すぎない。落ちる・急に動く表現は出さない。

## 3. 傾き
- 前後の軸は、端末の向きからは決めない。はじめに傾けている間に、いちばん大きく動いた軸を使う（すすむ・のる＝前後、ゆれる＝左右）。約15°まで傾けると決まる。
- 前の向きは、はじめに約6°以上を約0.3秒傾けた向き。
- 画面の下の「水平」ボタン：いまの持ち方を水平にして、軸と前の向きを覚え直す。端末の向き（たて・よこ）が変わったときも、覚え直す。
- 小さなゆれ（約2.5°まで）は数えない。傾きは、なめらかにして使う。
- 反応の角度：6°／8°（初期値）／12°。大人2回の測定（動き出し 7〜8°、自然な傾きのまんなか 13〜14°、いちばん大きく傾けると約46°）から決めた。
- 傾きが取れない端末・パソコンは「画面をなぞる」（指を右へずらすほど、前・右に傾けたのと同じ）。

## 4. 支援者メニュー（右上の点を1.2秒長押し）
- 場面（すすむ・ゆれる・のる）
- この場面：すすむ＝道の長さ・進む速さの上限・つぎの道にする／ゆれる＝のりもの・動かし方・ゆれの幅・ゆれの音／のる＝遊具の数
- みんな共通：反応の角度、いまの持ち方を水平にする、傾き（センサー）の状態と許可
- くわしく：場面の説明、操作の方法（端末を傾ける・画面をなぞる）、見える向き（そのまま・反対）、見た目（やさしい＝雲が動かない）、お祝いの強さ、音、肌の色（3）、説明をもう一度
- もとにもどす／とじる。画面の下に「とめる」「おしまい」「水平」

## 5. 約束
- 子どもの画面に文字を出さない。点滅なし。音はやわらかく、音量は支援者が調節。
- 名前・記録・声・顔・録音・写真を保存しない。カメラ・マイクは使わない。治療効果をうたわない。
- 傾きで動かすときは、画面に触れても何も起きない（のるで遊具を選ぶときだけ反応する）。
- 子どもの体を支えながら、同じ大人が端末を操作しない（大人2人で行う。1人のときは、画面の時間と体を動かす時間を分ける）。

## 6. 観察（支援者が紙に書く。アプリには残さない）
- すすむ：画面の人を見ているか。止まったことに気づくか。画面のあと、実物の手押し車で手を前に出そうとするか。
- ゆれる：揺れを見て、体や顔がゆるむか。そのあとの実物の揺れで、緊張するか、楽しむか。
- のる：絵を見たあと、その遊具へ向かうか。予告があると、乗るときの様子は変わるか。
- 画面に手を伸ばして、画面そのもので遊ぼうとするか（そうなら、画面の時間を短くする）。
