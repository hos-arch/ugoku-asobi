# うごく あそび (ugoku-asobi)
手押し車・ゆらゆら揺れる遊び・遊具に乗る遊びの前とあとに、画面で動きを見せる遊び。
参考：療育の実践書（「身体の調節」の課題を参考にした）。この仕様は、同書の考え方をもとに、私たちが画面用に解釈した試作です。

- **端末は大人が持って傾ける。子どもは端末を持たない**（画面で遊んでしまうと、体の動きにつながりにくいため）。子どもは画面を見て、そのあと実際に体を動かす（本物 → 画面 → 本物）。
- 場面
  - すすむ（手押し車）：端末を前に傾けると、手押し車の子どもが進む。水平に戻すと止まる。旗・おうちに着いたら、水平に戻すと次の道。
  - ゆれる（ゆりかご・ブランコ・ボート）：端末を左右に傾けると、同じ向きに揺れる。「自動でゆれる」もある。やわらかいゆれの音（なし・小・中）。
  - のる（遊具）：トランポリン・ブランコ・すべり台・三輪車・ローラースケート（2・3・5こ）。押すと、その遊具で遊ぶ様子がゆっくり見える（乗る前の予告）。ブランコは前後の傾きで揺れる。
- 傾き：前後の軸は、端末の向きではなく、はじめに傾けたときにいちばん大きく動いた軸で決める。反応の角度 6°／8°（初期値）／12°。動き出しは角度を超えて約0.3秒、止まるのは約60%を下回って約0.4秒。速さは約20°で上限。小さなゆれ（約2.5°まで）は数えない。
- 画面の下：とめる・おしまい・水平（いまの持ち方を水平にする。軸と前の向きも覚え直す）。
- 支援者メニュー（右上の点を1.2秒長押し）・くわしく・お祝いの強さは、他のアプリと同じ構成。傾きが取れない端末・パソコンでは「画面をなぞる」で動かせる。
- `public/index.html` 単一ファイル。Cloudflare Workers（assets）で公開。名前・記録は保存しない。カメラ・マイク不使用。
